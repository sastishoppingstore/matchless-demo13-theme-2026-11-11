# Matchless Demo13 WordPress Theme

- Design: 100% same visual style as Wafa demo13 (colors, layout, typography, animations, components).
- Content: Populated from local clone crawl of https://www.matchlesstravels.ca/ (all package/category/month pages and rates found in `/tmp/opencode/crawl`).
- Location: separate theme directory (does not modify Wafa Smart Tech site).

## Install
1. Zip this folder or copy `matchless-demo13-theme` into `wp-content/themes/`.
2. In WordPress admin, activate **Matchless Demo13**.
3. Set a static front page if desired (theme includes `front-page.php`).
